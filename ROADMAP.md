set of 120 high-value interview problems. New entries should add a missing
pattern or strengthen a thin topic rather than duplicate an existing exercise.

## Definition of done

Every new problem must include:

- A source link, approach explanation, and time/space complexity.
- Type-annotated, Python 3.9-compatible code.
- Edge-case assertions or unit tests.
- A matching website catalog entry and updated documentation count.
- A passing `python -m unittest discover -s tests -v` run.
